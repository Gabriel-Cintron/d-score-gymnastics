# App Review notes — 1.0.0

D-Score Gymnastics is a local-only men's artistic gymnastics routine planning utility. No account,
login, subscription, purchase, analytics, advertising, or network-backed user service is present.

To review the core flow:

1. Select **Skip tour** on first launch, or complete the three short onboarding pages.
2. Select **Floor Exercise** under Quick Start.
3. Select **Add element**, search or browse the catalogue, and add skills to see the live D-score
   explanation.
4. Use the event selector to inspect the other five events. Vault has its own single-vault picker;
   Pommel Horse exposes its sequence builder inside the element picker.
5. Open **Settings** to inspect the ruleset source cutoff, local backup/restore controls, privacy
   link, and local-data deletion.

All routine and preference data is stored locally in SQLite. The app does not request access to
contacts, location, photos, camera, microphone, health, motion, or fitness data. External links in
Settings open the public support, privacy, source, and license pages.

The calculator assumes entered elements receive technical recognition. It does not calculate an
execution score or official competition result. The app links to the official World Gymnastics rules
page as the authoritative source.

D-Score Gymnastics is an independent project. It is not affiliated with, endorsed by, or officially
authorized by World Gymnastics or the Fédération Internationale de Gymnastique (FIG).
