# What to Test — D-Score Gymnastics 1.0.0

Thank you for testing the first iPhone release. Please focus on real-device behavior that browser
automation cannot fully reproduce:

- Complete or skip onboarding, force-quit the app, and confirm that it does not unexpectedly return.
- Build and edit one routine on each of the six events. Check keyboards, scrolling, safe areas,
  sliders, modal dismissal, and dark/light mode.
- Create two all-arounds, switch between them, and verify the save/don't-save/cancel prompts.
- Save, rename, load, and delete a catalogue routine. Force-quit and relaunch to confirm
  persistence.
- Build a Pommel Horse Flop/Combined sequence and edit a stationary Russian's location.
- Export a backup, clear local data only after confirming the warning, and restore the backup.
- Try airplane mode after the app has been installed and opened once.

Report the iPhone model, iOS version, event, selected skills, expected result, and actual result.
For rules corrections, include the governing publication and page. Do not post private routine data
in a public issue.
