SUPPORT

How can we help?

Report a technical problem, suggest an improvement, or provide a source-backed scoring correction. Do not include private routine data unless it is necessary.

Email supportsupport@d-score.app Open a GitHub issueBest for reproducible bugs and source-linked rule corrections.

Where are my routines?

They are stored only in this browser or installed app. D-Score Gymnastics cannot recover local data from another device. Use Settings → Export backup before clearing storage, changing devices, or removing the app.

How do I install the web app?

On iPhone, open the calculator in Safari, use Share, then choose Add to Home Screen. On desktop browsers, use the install action offered in Settings or the browser menu. Load the app once while online before relying on offline access.

How should I report a scoring issue?

Include the event, entered skills, displayed result, expected result, and a citation to the applicable rule publication and page. Avoid attaching an entire copyrighted rulebook.

What is outside support scope?

The app cannot decide whether a performed skill should receive recognition, judge execution, or replace an official competition jury. Those decisions require qualified human judgment and the current governing publications.
