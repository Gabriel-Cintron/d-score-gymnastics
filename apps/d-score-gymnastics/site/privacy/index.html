PRIVACY POLICY

Your routines stay yours.

Effective 14 October 2026

Overview

D-Score Gymnastics is published and operated by Jose Gabriel Cintron. The app is designed to work without an account and does not collect, upload, sell, or share routine data.

Optional web analytics

Basic usage and search-term diagnostics are separate, optional choices in Settings. Both start off. Basic usage counts consenting browser profiles, visits, sessions, search counts, result counts and filter types. Search-term permission additionally sends short search terms and selection evidence to help improve catalog aliases. Random identifiers keep usage and search diagnostics separate. These records are pseudonymous while linked; they cannot establish an exact count of people.

We do not upload routines, routine names, scores, navigation paths, contact fields, precise location or fingerprints. We do not store IP addresses in the analytics database. Acquisition information contains referring domains and predefined campaign tags, not full URLs. Search screening rejects obvious contact details and URLs but cannot remove every possible personal detail. Do not enter personal information in searches. There are no advertising, replay or crash-reporting services.

Raw usage events are retained for 30 days; individual search episodes for seven days; linked activity and search evidence for 90 days. A minimal hashed installation registry prevents double-counting returning installations until deletion. Deidentified totals, growth summaries and historical records are retained indefinitely.

Settings can stop collection, clear queued events and request deletion of linked server records. An offline deletion is queued until connectivity returns. Previously deidentified totals remain. Clearing browser storage loses the local deletion credential and may count a later visit as another installation. Analytics identifiers, choices and queues are excluded from routine backups.

Native analytics remains disabled until a separately reviewed iOS release updates its disclosures. No account is required on either platform.

Cloudflare managed recovery history can retain earlier analytics records for up to seven additional days after deletion from active storage.

Local application data

Entered routines, saved all-arounds, preferences, and editor state are stored locally in IndexedDB on the web or SQLite in the native app. This information remains under the user's control and is not transmitted by D-Score Gymnastics.

Backups and deletion

Backup files are created only when the user asks to export one. The user chooses where that file is saved or shared. Settings includes separate controls to clear routine data and request analytics deletion. Removing browser storage or uninstalling the app may also delete local data.

Website delivery

The public website is delivered by Cloudflare Pages. Like most hosting providers, Cloudflare may process ordinary request information such as IP address, browser details, and timestamps under its own privacy terms. The operator receives only the optional first-party usage/search dashboard described above. Routine data is never combined with hosting request information. Analytics uses Cloudflare Workers and D1. Hosting necessarily processes network information under Cloudflare's privacy terms, independently of the app's own analytics records.

Contact and external links

If a user emails support or opens a GitHub issue, the information they choose to provide is handled by their email provider or GitHub under those services' terms. Public issues should not contain private routine or personal information.

Children's privacy

The app is a general-audience sports utility and does not request personal contact information or collect routine data. Optional search diagnostics may contain information users type, so keep personal information out of searches. There is no user account or attempt to identify people across devices.

Changes to this policy

Material changes will be published at this URL with a revised effective date. Features that introduce data collection will not be added without updating the policy and the applicable store disclosures first.

Contact

Privacy questions can be sent to support@d-score.app.
